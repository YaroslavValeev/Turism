До финальной приёмки витрины выполнен отдельный **visual polish pass** (только `apps/web`, без смены продуктовой логики).

### Что уже принято

- Wakesurf-first positioning, landing structure, long-form страница программы
- Assisted booking, одобренные отзывы, публичный API без `intakeSource`
- Интеграция контент-пака

### Что доработано визуально

- Hero: сцена с градиентом/паттерном, иерархия заголовков, блок статуса пилота, CTA
- Карусель направлений: полноразмерные слайды, нижний overlay, стрелки, индикаторы
- Карточки программ: акцентная полоса, метаданные строками, цена, теги
- Ритм секций: чередование фона, контейнер, отступы
- Типографика: масштаб clamp, line-height, сглаживание
- Страница программы: hero-блок, секции контента, форма заявки в карточке с полями `.mw-input`

### Что не делалось

- Изменение intake policy, расширение пилота, новые фичи

### Критерий приёмки

Интерфейс ощущается как **premium-utility**, pilot-ready, trust-first, operator-assisted — без смены смысла продуктовых правил.
