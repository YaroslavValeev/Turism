# KINOPOISK_INSPIRED_UI_ADAPTATION_EMAIL.md

Тема: Adapt Kinopoisk-like catalog UX patterns for MyWave without cloning the product

Привет.

Фиксируем новый визуально-UX вектор для публичной витрины:

# Kinopoisk-inspired adventure catalog

but adapted to MyWave Travel and not copied 1:1.

## Главная идея

Берём у Kinopoisk / streaming UIs:

- strong dark premium base
- content-first card system
- horizontal content rails
- topic chips / filters
- strong selection logic
- immersive program pages

Но адаптируем под:

- training-first product
- operator-assisted booking
- trust + safety
- Wakesurf-first pilot

## Что внедряем

### 1. Global visual direction

- dark premium background
- MyWave turquoise accent
- strong card surfaces
- bright CTA buttons
- clean typography
- high contrast hierarchy

### 2. Homepage structure

Собрать как streaming-style adventure catalog:

1. hero
2. chips / quick themes
3. horizontal rail: «Сейчас в пилоте»
4. horizontal rail: «Скоро в каталоге»
5. horizontal rail: «Для вашего формата»
6. how it works (cards)
7. organizers block
8. faq / footer

### 3. Card system

Карточки программ должны ощущаться как premium content cards:

- cover image
- badges
- title
- location
- dates
- duration
- level
- price from
- CTA

### 4. Filters / chips

Добавить expressive selection layer:

- Wakesurf
- SUP
- MTB
- Krasnodar
- Dubai
- Bodrum
- Новичок
- Средний
- Продвинутый
- 3 дня
- Family
- Progress
- Assisted booking

### 5. Program page

Сделать более immersive layout:

- big cover / hero
- quick facts panel
- description
- for whom
- by day
- included / not included
- equipment
- organizer / coach
- reviews
- similar programs
- application section

### 6. Mobile-first adaptation

- swipe rails
- sticky CTA
- compact chips
- strong card-first consumption

## Что не делать

- не копировать Kinopoisk literally
- не использовать their branding / identity
- не превращать product into a movie-service clone
- не жертвовать clarity ради visual mimicry
- не ломать Wakesurf-first pilot logic
