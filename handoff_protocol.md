# Handoff Protocol

## Любой handoff должен содержать
1. Контекст
2. Текущий статус
3. Что уже сделано
4. Что заблокировано
5. Кто следующий owner
6. Как выглядит done
7. Дедлайн

## Handoff founder -> team
- цель
- почему это важно
- ожидаемый артефакт
- дедлайн
- что нельзя ломать

## Handoff agent -> founder
- краткий вывод
- решение
- риски
- что требует подтверждения
- что можно запускать сразу

## Handoff ops -> legal/safety
- timeline
- involved parties
- screenshots / proof
- booking id
- requested decision
