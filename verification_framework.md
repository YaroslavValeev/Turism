# Verification Framework

## Level 1 — Listed
Есть реальный организатор и базовая карточка.

## Level 2 — Checked
Проверены:
- личность / юрстатус
- контакты
- реальность программы
- базовые медиа

## Level 3 — Verified
Проверены:
- 10+ отзывов
- рейтинг
- медиа-отчёты
- safety-поля в карточке
- согласие работать по правилам платформы

## Level 4 — Trusted by Platform
Дополнительно:
- личный опыт взаимодействия
- успешные закрытые заявки через платформу
- низкий уровень жалоб
- дисциплина по обновлению карточек
