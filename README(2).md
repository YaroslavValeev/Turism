# Founder OS Kit v3 — Team & AI Operating System

Этот набор продолжает Kit v2 и переводит проект из founder-only режима в режим управляемой команды.

## Для чего нужен этот kit
- распределить роли и ownership
- задать KPI по функциям
- создать единый weekly rhythm команды
- стандартизировать задачи для subagents / Cursor / AI-team
- снизить хаос в handoff между founder, людьми и агентами

## Базовые решения проекта, встроенные в kit
- монетизация: комиссия только с состоявшейся сделки
- текущий юрстатус старта: самозанятый, Валеев Ярослав Радионович
- verified organizer = личный опыт + медиа-отчёты + минимум 10 отзывов + рейтинг клиентов
- стартовая логика: niche catalog + assisted booking + manual verification + trust-first
