# Release Gate Checklist

## Gate 1 — Product
- key user flows work
- organizer flow works
- booking flow works
- critical cards display correctly

## Gate 2 — QA
- no blocker / critical defects
- regression done
- smoke tests ready
- staging signed off

## Gate 3 — Infra
- dev / staging / prod separated
- backup confirmed
- rollback plan confirmed
- monitoring active

## Gate 4 — Founder Approval
- release owner approves
- release notes prepared
- support knows what changed
