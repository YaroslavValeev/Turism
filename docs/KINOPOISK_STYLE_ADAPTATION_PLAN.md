# Kinopoisk-style adaptation plan — MyWave Travel (inspired, not clone)

**Назначение:** зафиксировать, какие паттерны «streaming / Kinopoisk-like» переносим в публичную витрину, как это ложится на текущий код и на pilot-логику (Wakesurf-first, assisted booking).  
**Не цель:** визуально или юридически копировать Kinopoisk / Premier / чужой бренд.

**Связанное решение:** [KINOPOISK_INSPIRED_UI_ADAPTATION_EMAIL.md](KINOPOISK_INSPIRED_UI_ADAPTATION_EMAIL.md).

---

## 1. Какие паттерны перенимаем

| Паттерн (источник идеи) | Как используем в MyWave |
|-------------------------|-------------------------|
| Тёмная премиальная база | Фон страницы и секций — глубокий нейтральный тёмный; акцент — фирменная бирюза MyWave (`--mw-accent`), не оранжевый Kinopoisk |
| Content-first карточки | Карточка программы = «обложка + метаданные + CTA», без лишнего текста в сетке |
| Горизонтальные «рейлы» | Секции с горизонтальным скроллом (snap), группировка по смыслу пилота и «ширине платформы» |
| Чипы / быстрые темы | Мультивыбор или toggle-фильтры по дисциплине, локации, уровню, тегам из контента — **без** смешения с операторскими полями в API |
| Сильная иерархия | Крупный заголовок секции, вторичный текст приглушён, CTA контрастный |
| Immersive страница сущности | Страница программы: крупная обложка, блок фактов, далее секции контента и доверия |
| Mobile-first | Липкий CTA заявки, компактные чипы, рейлы со свайпом |

**Что явно не копируем:** логотипы, шрифты, сетку пиксель-в-пиксель, навигацию сервиса «как у стриминга», рейтинги как у кино, если это вводит в заблуждение относительно турпродукта.

## 2. Домашняя страница: текущее состояние и блоки к рефакторингу

**Файлы:** `apps/web/src/app/page.tsx`, `apps/web/src/components/*`, `apps/web/src/app/globals.css`, контент `apps/web/src/content/pilotLanding.ts`.

| Блок (целевая структура из письма) | Сейчас в коде | Действие |
|-----------------------------------|---------------|----------|
| 1. Hero | Единый блок: headline → `HeroFilmstrip` → CTA (`mw-hero-visual--filmstrip`) | Сохранить **логику** первого экрана; обложить **темой** (тёмный фон, контраст текста/кнопок). При необходимости — отдельные токены для hero, не ломая принятую композицию filmstrip |
| 2. Chips / quick themes | Нет отдельного ряда чипов; фильтры только в секции каталога (select + даты) | Добавить **ряд чипов** над рейлами или над каталогом; часть тегов — клиентские фильтры по `program` + `teaser.tags` |
| 3. Rail «Сейчас в пилоте» | Программы в одной сетке `program-grid` после фильтров | Выделить **подмножество** `programs` (pilot scope) в горизонтальный rail с `scroll-snap` |
| 4. Rail «Скоро в каталоге» | Контент частично в текстах лендинга (Dubai/Bodrum), не как rail | **Контентно:** карточки-заглушки или ссылки на mailto; **технически:** отдельный массив из `pilotLanding` / статический контент, не влияя на публичный API, пока нет программ |
| 5. Rail «Для вашего формата» | Секция «Для кого этот формат» — `forWhomCards` в сетке | Перевести в **горизонтальный rail** карточек или в чипы + связанный rail программ |
| 6. How it works | `steps` в `steps-grid` | Оформить как **ряд карточек** в стиле премиум-поверхности (как в плане), без смены смысла |
| 7. Organizers | Секция `organizersBlock` | Визуально усилить блок как «канал доверия»: контрастная плашка, CTA |
| 8. FAQ / footer | `Faq` + `LandingFooter` | Наследить под тёмную тему (фон футера, ссылки) |

**Trust:** `TrustBar` сейчас сразу под hero — при желании перенести ниже или встроить в первый скролл после рейла «в пилоте», чтобы повторить ритм «контент → доверие» (решение на этапе вёрстки).

## 3. Карточки программ (card system)

**Файлы:** `apps/web/src/components/ProgramCard.tsx`, стили `.mw-program-card*` в `globals.css`.

| Элемент | Сейчас | План |
|---------|--------|------|
| Обложка | Есть (`media` или градиент-плейсхолдер) | Сохранить; на тёмной теме — чёткая рамка/тень «surface» |
| Badges | Пилот, Wakesurf-first, assisted, extra из teaser | Выровнять визуально «как метки контента»; не перегружать |
| Мета | Локация, даты, формат, организатор | Оставить; при необходимости компактная строка «даты · уровень · дни» |
| CTA | «Открыть программу» | Сохранить; на mobile рассмотреть **вторичный** мини-CTA в rail (как опция) |

**Данные:** по-прежнему из `GET /programs`; чипы не должны требовать новых обязательных полей API — только фильтрация на клиенте и теги из `pilotProgramTeasers` / контента.

## 4. Страница программы (immersive)

**Файл:** `apps/web/src/app/program/[id]/page.tsx`, стили `mw-content-section`, `globals.css`.

| Зона | Сейчас | План |
|------|--------|------|
| Верх | Заголовок + мета + текстовые секции | **Hero обложки:** первое изображение из `media` или плейсхолдер; под ним — быстрые факты (даты, уровень, цена, локация) в одной панели |
| Описание | Секции через `SectionBlock` + overrides | Сохранить порядок смысла; усилить типографику и отступы «премиум» |
| Отзывы | Список публичных отзывов | Плашка «только после модерации» при необходимости; визуально отделить от основного текста |
| Заявка | Форма внизу | **Sticky CTA** на mobile: «Оставить заявку» → якорь на форму |
| Похожие программы | Нет | **Опционально:** `GET /programs` + фильтр по `discipline`/`region`, исключая `id` (не блокер первой волны) |

## 5. Mobile

- **Рейлы:** `overflow-x: auto`, `scroll-snap-type: x mandatory`, скрытый или минимальный scrollbar; опционально стрелки только на `md+`.
- **Чипы:** горизонтальный скролл, без переноса на всю ширину экрана.
- **Sticky CTA:** на `program/[id]` — фиксированная нижняя панель с одной кнопкой + ссылка «Подробности» при необходимости.
- **Каталог:** сохранить доступность фильтров (не только свайп).

## 6. Приоритет внедрения

1. **P0 — Дизайн-токены и тёмная тема:** переменные в `:root` / `[data-theme="dark"]`, фон `body`, поверхности карточек, текст, кнопки; не ломать контраст WCAG.
2. **P1 — Главная:** чипы + 1–2 горизонтальных рейла («в пилоте», опционально «скоро»); рефакторинг сетки каталога под «рейл или сетка» в зависимости от breakpoint.
3. **P2 — ProgramCard + program page:** визуальное усиление карточек и hero на странице программы, sticky CTA.
4. **P3 — Полировка:** анимации скролла, микро-состояния чипов, «похожие программы».

**Согласование:** если действует режим «only pilot signals» без нового UX-спринта, внедрение по приоритетам выносится на отдельное решение Owner/GM; этот документ — **план**, а не автоматический go.

---

## 7. Что остаётся вне scope

- Оплата на сайте, self-serve бронирование без оператора.
- Публичные отзывы без модерации (канон уже зафиксирован в API).
- Подмена турпродукта «киношным» опытом (рейтинги, «топ-250», обманные метрики).
- Копирование чужого бренда, иконографики и логотипов.
- Расширение pilot wedge без сигнала и решения Owner.
- Массовые изменения API только ради UI — только если появится чёткая необходимость (например, similar programs).

## 9. Критерий готовности первой волны

- Публичная витрина читается как **тёмный премиум-каталог** с бирюзовым акцентом MyWave.
- Пилот **Wakesurf-first** и assisted booking **очевидны** без клика.
- Нет визуального смешения с брендом Kinopoisk; нет «киношных» элементов, вводящих в заблуждение.
- Лендинг и страница программы остаются **доступными** (контраст, фокус, кликабельные зоны).
