# Инвентарь UX-текстов: замены и удаления (Russia + factual trust)

Источник правил: ТЗ продукта (без «проверенный тур/организатор», «гарантия лучшей цены», «безопасный тур», платформа не выдаёт себя за организатора; география — только Россия).

---

## Часть A. Обязательные целевые формулировки (вставить в UI)

## Часть C. Blacklist: полное удаление или запрет в новых текстах

Удалить с пользовательской витрины (не использовать в новых макетах):

- Проверенный организатор / проверенный тур / проверенные организаторы (как обещание платформы)
- Надёжный организатор / эксперт (как ярлык платформы)
- Гарантия лучшей цены / гарантия низкой цены / лучшая цена
- Безопасный тур / безопасные туры (как продуктовое обещание)
- Топ (как оценочный маркетинг без методики)
- «Используй планету…», «весь мир», «по миру», не-РФ слайды в hero как будто в ассортименте
- Англоязычные статусы **trusted / verified** в пользовательском UI (внутренние enum оставить в коде, подписи — человекочитаемые нейтральные)

**Исключение:** слово «проверка» допустимо в значении **процедуры** («проверка данных карточки», «проверка соответствия правилам публикации»), но не как «мы гарантируем качество поездки».

## Часть E. Полнота инвентаря

После внедрения прототипов — повторный `grep` по репозиторию:

`проверен|надежн|гарант|безопасн тур|лучш цен|топ тур|забронир|купить|по миру|планет`

Исключить ложные срабатывания (например «Проверьте формат email» — **не** менять).
