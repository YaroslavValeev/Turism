## Недавно закрыто (текущий проход)

| Тема | Статус |
|------|--------|
| Блоки карточки «поездка» (что взять, где жить, как добраться, что посмотреть, план Б) + мягкие подсказки платформы | Поля в БД + API + публичная карточка + черновик при **создании** программы в админке |
| Поля организатора: сертификаты, страховка, план ЧП, оборудование | Колонки в БД + API PATCH/POST + отображение на карточке программы (если заполнены) |
| Сезонность в каталоге | Фильтр сезона по месяцу старта + «Ближайшие старты (14 дней)» на главной (клиентская фильтрация) |
| **`durationDays` только derived** | Общая функция в `@mywave/shared-types`; POST/PATCH не принимают отдельное изменение `durationDays`; publish gate проверяет совпадение с календарём; см. `docs/qa/DATE_EDIT_RULES.md` |
