# Definition of Done by Stream

## Supply
Done, если:
- организатор прошёл нужный статус pipeline
- карточка программы заполнена на 100%
- есть owner
- есть next step

## Demand
Done, если:
- lead получил статус
- organizer уведомлён
- следующий шаг понятен
- есть способ зафиксировать outcome

## Trust & Safety
Done, если:
- уровень проверки зафиксирован
- доказательства приложены
- решение logged
- есть recommendation

## Product
Done, если:
- acceptance criteria выполнены
- QA checklist пройден
- нет blocker/critical
- release gate подтверждён

## Finance
Done, если:
- сделка зафиксирована
- сумма подтверждена
- комиссия начислена
- статус оплаты комиссии понятен
