# Smoke после деплоя (MyWave Travel)

Короткая проверка **на целевом окружении** (staging → prod) сразу после выката. Не заменяет полный регресс; ловит «сломали прод».

Локальная и мобильная приёмка до деплоя: [`docs/deployment/PRE_DEPLOY_LOCAL_AND_MOBILE.md`](../deployment/PRE_DEPLOY_LOCAL_AND_MOBILE.md).

---

## 1. Доступность

- [ ] Публичный сайт открывается, нет 5xx на главной и каталоге.
- [ ] Админка открывается (если в релизе менялись auth/маршруты админки).

## 2. Критический путь участника

- [ ] Каталог → карточка программы (или минимум один опубликованный сценарий из [`BROWSER_CHECK_ROUTES.md`](./BROWSER_CHECK_ROUTES.md)).
- [ ] Если в релизе были правки **мобильной вёрстки** — выборочно [`MOBILE_CHECK_ROUTES.md`](./MOBILE_CHECK_ROUTES.md).

## 3. API (если в релизе менялся backend)

- [ ] Один-два ключевых публичных эндпоинта (например список программ / health), ожидаемый JSON и коды.

## 4. Конфиг и секреты

- [ ] Нет «пустых» обязательных env на сервере; сервисы поднялись (логи без фатала при старте).

## 5. Откат

- [ ] Зафиксирован **предыдущий** рабочий образ/версия или команда отката (кто и как откатывает — по внутреннему runbook).

---

*После smoke — при сбое: stop rollout, откат, постмортем в тикете.*
