# Program Card Definition

Обязательные поля карточки программы:
1. Название программы
2. Дисциплина
3. Локация
4. Даты
5. Длительность
6. Для кого программа
7. Уровень подготовки
8. Уровень риска
9. Что включено
10. Что не включено
11. Требования к экипировке
12. Медицинские ограничения
13. Программа по дням
14. Кто проводит
15. Почему организатору можно доверять
16. Фото / видео / медиа
17. Отзывы
18. Условия отмен
19. Что происходит после заявки
20. CTA
