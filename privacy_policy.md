
# Политика обработки персональных данных

## 1. Общие положения
Настоящая политика описывает порядок обработки персональных данных пользователей платформы.

## 2. Какие данные собираются
- имя
- телефон
- email
- данные бронирований

## 3. Цели обработки
- регистрация пользователя
- связь с организатором
- обработка заявок
- улучшение сервиса

## 4. Передача данных
Данные могут передаваться организаторам программ для исполнения бронирования.

## 5. Защита данных
Платформа принимает технические и организационные меры для защиты персональных данных.
