# Post-Release 24h Checklist

## 0-15 минут
- [ ] Проверить `health` API.
- [ ] Проверить загрузку главной и каталога.
- [ ] Проверить открытие карточки программы.
- [ ] Проверить отправку тестовой заявки и уведомление Telegram/email.

## 15-60 минут
- [ ] Проверить вход в админку и открытие `Bookings`.
- [ ] Проверить логи API и nginx на 5xx.
- [ ] Проверить отсутствие резкого роста 429/401/500.

## 1-6 часов
- [ ] Проверить CPU/RAM/disk на сервере.
- [ ] Проверить очередь/доставку email и Telegram.
- [ ] Проверить появление реальных заявок в админке.

## 6-24 часа
- [ ] Сверить конверсию: просмотры -> заявки -> подтверждения.
- [ ] Проверить backup DB по расписанию и факт создания файла.
- [ ] Закрыть инциденты blocker/critical (если появились).

## Условия emergency rollback
- [ ] 5xx стабильно выше порога.
- [ ] Потеря доступа к админке/каталогу.
- [ ] Некорректные миграции данных.
