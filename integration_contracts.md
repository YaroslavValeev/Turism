# Integration Contracts

## Email / notification service
Must support:
- new lead alerts
- organizer reminders
- review requests
- refund / complaint updates

## Analytics
Must receive:
- program_view
- inquiry_submitted
- booking_status_changed
- review_submitted
- commission_accrued

## CRM / admin layer
Must support:
- canonical booking statuses
- organizer verification statuses
- incident queue
- revenue reconciliation queue

## Payment-adjacent logic
At MVP, payment may happen off-platform.
System must still support:
- deal confirmation
- GMV entry
- commission accrual
- payment collection status
