# Funnel Metrics Model

## Supply funnel
sourced organizer -> screened -> contacted -> call_done -> interested -> docs_pending -> verification_review -> listed -> verified

## Demand funnel
visitor -> program_view -> inquiry -> lead_new -> contacted -> booked -> paid -> completed -> reviewed

## Revenue funnel
completed deal -> commission evidence -> accrued -> invoiced -> collected

## Must-track conversions
- program_view -> inquiry
- lead_new -> contacted
- contacted -> booked
- booked -> completed
- completed -> reviewed
- completed -> accrued commission
- accrued -> collected commission
