# MyWaveTour — первый экран, шаг 1

## Согласовано пользователем

- Продукт: каталог спортивных поездок MyWaveTour и его Telegram Mini App, не Event App.
- Заголовок: **«Найди свой выезд. Будь на своей волне.»**
- Логотип должен быть заметнее; работа пошаговая, без одновременного редизайна всех страниц.

## Предлагаемый отдельный макет

- Сохранить существующий официальный логотип; ориентир ширины 240–280 px desktop, 180–210 px mobile с сохранением пропорций. Проверить реальную читаемость, не растягивать bitmap сверх качества.
- Слева заголовок, короткое объяснение выбора поездки и один главный CTA «Смотреть выезды»; вторичный — «Как это работает».
- Справа/на фоне — один спокойный outdoor-визуал: движение, вода/горы, пространство. Без коллажа из множества дисциплин, мелких плашек и ложных гарантий.
- Бирюзовый акцент, светлые поверхности, тёмный контрастный текст; сохранить узнаваемость текущего сайта.
- На mobile: логотип → заголовок → пояснение → CTA → изображение; важное действие не скрывать под декоративной картинкой.
- Первый макет не меняет каталог, PDP, формы, публикацию или статусы программ.

Общее направление выбранных ранее пользователем вариантов: природа и открытое пространство, выразительная фотография, движение, ограниченная палитра. Это направление, а не разрешение копировать рекламные обещания/чужой бренд.
