# Handoff to Dev Team

## Что считать каноническим
1. PRD — продуктовые границы
2. Technical spec — архитектурная рамка
3. Kits v2-v6 — operating logic, statuses, delivery sequence
4. Legal pack — обязательные ограничения и flows

## Что нельзя менять без founder approval
- монетизационную модель
- north star
- verification logic
- canonical booking statuses
- revenue accrual rules
- legal disclaimers / cancellation logic

## Что команда должна вести постоянно
- sprint board
- release notes
- decision log
- incident log
- commission reconciliation log
- dashboard metrics
