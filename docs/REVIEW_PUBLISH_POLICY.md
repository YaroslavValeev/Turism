# Review publish policy

Политика модерации и публикации отзывов. **Public review layer в текущем пакете отсутствует;** отзывы видны только в admin-очереди.

## Статусы модерации

| Статус | Значение |
|--------|----------|
| **pending** | Отзыв создан, не проверен. Виден только ops/admin. Не используется ни в каком публичном контенте. |
| **approved** | Прошёл модерацию, **разрешён** к потенциальному использованию в публичном слое. Публичный слой отзывов пока не реализован — approved лишь даёт право на показ после его появления. |
| **rejected** | Не допускается к публикации (нарушение правил, оскорбления, персональные данные третьих лиц и т.п.). |

## Правила

1. **Создание отзыва** — только для бронирований со статусом **completed**. Один отзыв на одно бронирование (unique bookingId).
2. **Кто переводит статус:** только авторизованный admin (ops). Смена через PATCH /reviews/:id/moderation. В audit_log фиксируется смена moderationStatus.
3. **Approved не течёт наружу без решения:** любой будущий публичный слой отзывов должен явно фильтровать по `moderationStatus = 'approved'` и быть включён отдельным продуктовым решением. Сейчас публичного API/UI отзывов нет — утечки нет.
4. **Чек-лист модерации (рекомендуемый):** нет оскорблений, нет персональных данных третьих лиц, нет спама/рекламы; при сомнениях — оставить pending или rejected.

## Что запрещено до явной moderation/publish policy

- Публичный API отзывов (GET отзывов без admin auth).
- Публичная выдача отзывов на лендинге/каталоге.
- Любое отображение отзывов с moderationStatus != approved, если когда-либо появится публичный слой.

Итог: policy зафиксирована письменно; public review layer отсутствует; approved не начинает случайно течь наружу без отдельного решения.
