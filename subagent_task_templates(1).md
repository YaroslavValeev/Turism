# Subagent Task Templates

## 1. Product Agent
Задача:
Нужно улучшить [экран / flow / карточку / status model].

Выход:
- problem statement
- proposed change
- acceptance criteria
- dependencies
- rollout risk

## 2. Partnerships Agent
Задача:
Нужно оценить / привлечь / дожать организатора [название].

Выход:
- fit assessment
- objections
- next best step
- success probability
- owner action

## 3. Trust & Safety Agent
Задача:
Нужно проверить программу / организатора / кейс жалобы.

Выход:
- compliance summary
- safety gaps
- documentation gaps
- recommendation: listed / checked / verified / reject

## 4. Ops Agent
Задача:
Нужно разрулить кейс по заявке / отмене / возврату / жалобе.

Выход:
- factual timeline
- responsible side
- immediate action
- customer-facing resolution
- escalation need

## 5. Content & Growth Agent
Задача:
Нужно сделать материал для привлечения [аудитории].

Выход:
- content angle
- CTA
- format
- funnel role
- repurposing plan

## 6. Tech Agent
Задача:
Нужно спроектировать / исправить / выпустить [функцию].

Выход:
- technical approach
- data model impact
- QA impact
- release plan
- rollback note
