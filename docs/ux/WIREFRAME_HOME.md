## 2. Навигация (ТЗ §2.1)

| Пункт меню            | Поведение (wireframe) |
|-----------------------|------------------------|
| Направления по России | Якорь/страница с региональными тегами + фильтр `region` |
| Дисциплины            | Якорь/страница таксономии дисциплин |
| Ближайшие старты      | Пресет фильтра «старты в N дней» + сортировка по дате |
| Сезоны                | Пресет зима/лето/… |
| Организаторам         | `/organizers/program` + блок верификации как процесс, не «надёжность» |
| Отзывы                | Отдельная витрина или якорь на блок социального доказательства (когда будет) |
| Как это работает      | Сводка шагов заявки + роль платформы (посредник) |

**Убрать из шапки:** выбор «страны» как универсального мира; подписи «Укажите страну»; любые международные подборки в контенте hero.

## 3. Hero — обязательные тексты (ТЗ §1.1)

| Элемент   | Текст |
|-----------|--------|
| H1        | Кэмпы, туры и спортивные выезды по России |
| Подзаголовок | Сравнивайте программы российских организаторов по дисциплине, региону, сезону и уровню подготовки. Читайте отзывы участников и отправляйте заявку организатору через платформу. |
| Primary CTA | Подобрать выезд |
| Secondary CTA | Разместить программу |

**Микрокопирайт под CTA (опционально):** «Наличие мест и условия участия подтверждает организатор. Платформа передаёт заявку и помогает с коммуникацией.»

---

## 4. Factual strip (ТЗ §1.4)

Заменяет маркетинговый trust-bar. Четыре коротких тезиса **без** «проверенный / лучшая цена / безопасный тур».

---

## 5. Отличия от текущего UI (для разработки)

| Сейчас | Цель |
|--------|------|
| `hero` из `pilotLanding` — «агрегатор экстремальных…», «планета» | Новый hero-копирайт + Russia-only |
| `TrustBar` + `trustCards` с «Проверенные организаторы» | `FactualTrustStrip` с 4 фактами из ТЗ |
| Фильтр в шапке «Направление / страна» | Только Россия: регион/локация или «Регион России» |
| `COUNTRY_BY_REGION` с ОАЭ/Турция/Чили | Удалить не-РФ из логики витрины или скрыть до появления не-РФ программ |
| Метрики hero «программ / организаторов / мест» | Оставить по желанию прототипа; не противоречить позиционированию |

---

## 6. Приёмка wireframe главной

- [ ] Первый экран читаетcя как Россия + спорт/актив, не «мировой travel».
- [ ] Нет запрещённой лексики платформенных обещаний.
- [ ] Есть быстрые сценарии + подборки карточек + 4 каталоговых входа.
- [ ] CTA ведут в каталог с пресетами или на форму организатора.
