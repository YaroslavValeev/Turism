# Главная MyWaveTour: спорт на первом плане

Выбранный владельцем вариант: компактная 3D-навигация, слоган «Выбирай свой спортивный отдых», заметные даты и быстрый переход к программам. Альтернатива, предложенная до реализации: больше фотографий направлений и слоган «Твой спорт. Твоя следующая поездка».

## Область изменения

- Карусель остаётся сразу под логотипом, во всю доступную ширину. Высота сокращена примерно вдвое: 273–301 px на проверенных ширинах 390–1920 px; на 320 px длинная подпись переносится, высота 294 px.
- Видимые основания фигур лежат на одной линии. Прозрачные поля исходных изображений учитываются CSS-окнами, сами 15 WebP не изменены. Перспектива и уменьшение боковых фигур сохранены.
- Одинаковые скульптуры распределяются по окружности; два сноубордиста разделены пятью и более позициями, включая стык последней и первой дисциплин. Исходные названия, ссылки и фильтры сохранены. Категория wildlife по прежнему исключена только из карусели.
- Слово «Направления» над каруселью удалено. Кнопка «?», стрелки и счётчик дисциплин убраны по уточнению владельца. Для скринридера инструкция сцены доступна постоянно. Пауза/продолжение — круглая кнопка 44 × 44 px с одной SVG-иконкой и доступным именем.
- Автовращение непрерывное: одна дисциплина за 4 секунды с постоянной угловой скоростью. Положение рассчитывается по времени requestAnimationFrame; React обновляет подпись только при смене ближайшей к центру фигуры. CSS-переходов и интервалов с остановками нет. Стык кольца скрыт, края появляются постепенно; масштаб и глубина меняются плавно относительно центра. Пауза, reduced motion, остановка при наведении/клавиатурном фокусе, уходе со страницы и из видимой области сохранены. Возобновление не догоняет пропущенное время. Колесо, свайп и клавиши продолжают выбирать фигуры вручную.
- Главный блок: короткий слоган, читаемое описание, основной CTA «Подобрать выезд», данные каталога и компактное раскрытие условий работы платформы. Предложение справа сохраняет реальные данные. Недоступная обложка получает существующий резервный рисунок.
- Даты вынесены из закрытых details под заголовки карточек, включая ближайшие старты. Используется существующий formatDateRangeRu. Сезонные окна on_request подписываются как «По запросу», некорректные даты — «Даты уточняются».
- SequencePager используется в турах/кемпах и горячих предложениях: две стрелки и компактный счётчик. В карусели дисциплин он удалён по уточнению владельца. Концы списка туров не закольцованы. Выбор фильтра сбрасывает страницу. Длинный ряд номеров удалён.
- Минимальная ширина карточек общего каталога ограничена шириной контейнера: устранено прежнее переполнение на 320 px.
- При сужении набора главных предложений текущий индекс проверяется уже при render, до reset-effect. Переход к дисциплине с меньшим числом предложений больше не обращается к undefined.
- Техническая метка Unknown не выводится в главном предложении; в карусели эта группа подписана «Другие выезды» с исходной ссылкой. Данные каталога не переименовываются.

## Проверка

Локально (PowerShell, корень checkout):

```powershell
pnpm run test:web:ux
pnpm --filter web exec tsc --noEmit
pnpm --filter web build
```

Новые unit-проверки покрывают сохранение исходных ссылок и массива дисциплин, распределение повторов на круге, пустой и одиночный набор, границы окон изображений, однодневные и переходящие через месяц/год выезды, on_request, неверные даты и часовой пояс участника.

Проверка браузером: 320, 390, 640, 768, 1024, 1440 и 1920 px. Проверить непрерывность полного оборота, общий нижний край и отсутствие обрезанных голов/оборудования, колесо/горизонтальный жест, Enter на сцене, иконку паузы/продолжения и отсутствие «?»/стрелок/счётчика в карусели, смену страниц и сброс фильтра, даты без раскрытия details. Новые unit-проверки движения сравнивают расчёт при 30/60/120 fps, дробный переход через стык кольца, пустой/одиночный список и отсутствие скачка масштаба в центре. Физический сенсорный экран и системная настройка reduced motion отдельно не подтверждаются эмуляцией ширины.

Локальная проверка интерфейса использует свежий публичный GET-снимок каталога; относительные URL обложек привязаны к публичному origin только в незакоммиченном fixture. POST отклоняется, записи в production/БД/Telegram не выполняются.

Docker: официальный apps/web/Dockerfile; запуск отдельного образа с --network none без публикации портов. Проверить GET /, утверждённый SHA256 вертолёта и наличие нового слогана/общего компонента навигации в собранном frontend.

Правила доступности: [управление каруселью W3C](https://www.w3.org/WAI/tutorials/carousels/).

## Публикация и откат

Одна логическая frontend-правка, без изменений Compose, env, API, БД и Telegram. Публикация через существующий scripts/production/deploy-web-carousel.sh с закреплённым SHA после CI. До публикации проверить свободное место и health; помощник сохраняет старый web-образ, проверяет сохранность защищённых сервисов и печатает точную команду отката. Результат локальных проверок не считается свидетельством публикации.
