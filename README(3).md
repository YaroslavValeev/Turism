# Founder OS Kit v4 — Partnerships / Sales / Revenue System

Этот набор переводит проект из режима "строим платформу" в режим
"системно подключаем организаторов, партнёров и первые revenue deals".

## Что внутри

- partnership_strategy.md
- organizer_pitch_onepager.md
- partner_pitch_onepager.md
- outreach_sequences.md
- discovery_call_script.md
- objections_handling.md
- first_10_revenue_deals_plan.md
- partner_package_structure.md
- commission_rules.md
- organizer_onboarding_checklist.md
- media_partnership_pack.md
- organizer_sales_pipeline.csv
- partner_pipeline.csv
- deal_tracking.csv
- revenue_deal_scorecard.csv
- offer_matrix.csv
- outreach_tracker.csv
- partner_fit_matrix.csv
- monthly_revenue_forecast_template.csv

## Базовые решения, встроенные в kit
- монетизация: комиссия только с состоявшейся сделки
- текущий юрстатус старта: самозанятый, Валеев Ярослав Радионович
- trust-first модель: assisted booking + manual verification
- verified organizer = личный опыт + медиа + минимум 10 отзывов + рейтинг

## Как использовать
1. Зафиксируй 1 стартовую нишу и 1 стартовый регион.
2. Заполни organizer_sales_pipeline.csv по первым 30 кандидатам.
3. Заполни partner_pipeline.csv по первым 20 партнёрам.
4. Используй outreach_sequences.md для первых касаний.
5. Каждый реальный разговор и сделку веди в deal_tracking.csv.
6. Раз в неделю обновляй monthly_revenue_forecast_template.csv.
