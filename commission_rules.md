# Commission Rules

## Базовый принцип
Комиссия берётся только с реально состоявшейся сделки.

## Сделка считается состоявшейся, если
- пользователь был передан организатору через платформу
- организатор подтвердил, что бронирование произошло
- есть подтверждённая сумма сделки
- статус сделки = completed / paid

## Что нужно фиксировать
- booking id
- program
- organizer
- дата
- сумма
- статус
- сумма комиссии
- дата фактической оплаты комиссии

## Стартовая логика
- без предоплаты за размещение
- без pay-to-play
- trust-first партнёрская модель
