# Partner Package Structure

## 1. Light package
- взаимная ссылка / mention
- совместная подборка
- referral code

## 2. Content package
- co-branded article / guide
- Telegram / social cross-post
- post-trip story / media report

## 3. Distribution package
- dedicated mailing / channel feature
- niche landing page
- seasonal collection

## 4. Strategic package
- recurring seasonal partnership
- privileged organizer / media loop
- data / insight sharing
